# 🦖 Français avec Dino

> **Une application web pour apprendre le français par la pratique.**  
> **A web application for learning French through practice.**

Dino combine des cours structurés, du vocabulaire, de la grammaire, des exercices et des situations concrètes, avec un support pédagogique en persan.

Dino combines structured lessons, vocabulary, grammar, exercises and practical situations, with Persian learning support.

## En bref · At a glance

- 🎯 Contenus CECRL / CEFR content from **A1 to C2** — coverage varies by module
- 📚 Grammaire / Grammar
- 🧠 Vocabulaire / Vocabulary
- ✈️ Français de voyage / Travel French
- 📝 Exercices intégrés / Built-in exercises
- 🇮🇷 Support français ↔ persan / French ↔ Persian support
- 💾 Progression enregistrée localement / Progress stored locally
- 🧪 TypeScript + données JSON / TypeScript + JSON data

> **État / Status:** projet en développement. Grammaire, Vocabulaire et Voyage disposent déjà de vrais parcours ; Quotidien, Jeux, la page générale Exercices et Profil sont encore en construction.
